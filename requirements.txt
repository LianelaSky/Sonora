# ==============================================================================
# Windows Native Features & Desktop Integration:
# ==============================================================================
# 1. Direct Windows 11 Desktop Installation (1-Click PWA App):
#    - Native Windows Start Menu & Taskbar pinning
#    - Windows 11 Window Controls Overlay (DWM Mica/Acrylic frame)
#    - Windows File Explorer file association (.mp3, .flac, .wav, .m4a, .alac)
#    - Windows Volume Mixer & Action Center Toast Notifications
#
# 2. Standalone Windows Executable (.exe / MSI via Electron):
#    - Run in Electron: npm run electron:dev
#    - Build Windows Installer: npm run electron:build
#    - Build Portable Windows .exe: npm run electron:dist
#    - Windows Taskbar Thumbnail Toolbar (hover mini player preview)
#    - Windows System Tray minimize and hardware media keys
# ==============================================================================
# Browser APIs & System Features Leveraged:
# ==============================================================================
# - Web Audio API (AudioContext, BiquadFilterNode, AnalyserNode, GainNode)
# - File System Access API (window.showDirectoryPicker for Windows folders)
# - IndexedDB (Native browser persistent storage for local library & audio blobs)
# - Media Session API (navigator.mediaSession for background audio & lock screen)
# - Open APIs: LRCLIB (synced lyrics API), iTunes Search API (album artwork)
# ==============================================================================
